# Bundled fonts

The font files in this directory are packaged locally. The front end does not
connect to Google Fonts or any other remote font service.

## Inter

- Source: https://fonts.google.com/specimen/Inter
- Upstream: https://github.com/rsms/inter
- Copyright: The Inter Project Authors
- License: SIL Open Font License 1.1
- License file: `inter/OFL.txt`
- Included subsets: Latin and Latin Extended
- Included styles: Upright variable, weights 400–900

## Source Serif 4

- Source: https://fonts.google.com/specimen/Source+Serif+4
- Upstream: https://github.com/adobe-fonts/source-serif
- Copyright: The Source Serif 4 Project Authors
- License: SIL Open Font License 1.1
- License file: `source-serif-4/OFL.txt`
- Included subsets: Latin and Latin Extended
- Included styles: Upright and italic variable, weights 400–800
