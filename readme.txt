== Description ==

Kahel is a Full Site Editing theme designed for blogs, magazines, and editorial websites. It includes coordinated templates, template parts, block patterns, a custom color palette, and locally hosted fonts.

== Installation ==

1. In your WordPress dashboard, go to Appearance > Themes > Add New.
2. Upload the Kahel theme archive and activate it.
3. Open Appearance > Editor to customize the site styles and templates.
